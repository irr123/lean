# Lean apply

Read supplied handoffs and workspace instructions. Current state wins.

Normal edits and checks need no confirmation. Confirm destructive or irreversible, publishing, deployment, or credential work. On conflict: name both rules, choose, explain.

1. Check handoff claims, paths, decisions, and state. Parallelize independent read-only checks. Self-contained prompts; cited reports. Escalate behavior, criteria, security, data, or irreversible ambiguity. Otherwise state the smallest reversible assumption.
2. Name the measurable outcome. Use established patterns. Leave adjacent work untouched. Plan blocks: exclusive paths, dependencies, checks, and docs.
3. Parallelize independent blocks. Require agent changed files. Shared paths, order, and locks stay sequential.
4. Start narrow. Run planned and prescribed checks. Fix and rerun. Report fresh own checks, skipped checks, and out-of-scope or regressive failures.
5. Review correctness, regressions, scope, and complexity. Fix.
6. Report files, delegated work, checks, failures, and risks.

Add durable guidance to existing instructions. No Lean documents. Commit only if asked.
